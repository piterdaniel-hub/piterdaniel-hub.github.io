Maîtrise algorithme, la programmation & le code

De débutant à développeur

Dans cet article, j'explique ce que j'apprends sur les algorithmes, la programmation et le code, étape par étape.

1. Qu'est-ce qu'un algorithme ?

Un algorithme est une suite d'instructions claires pour résoudre un problème.

2. Qu'est-ce que la programmation ?

Programmer, c'est écrire ces instructions dans un langage que l'ordinateur comprend.

3. Qu'est-ce que le code ?

Le code, ce sont les instructions écrites par le programmeur, par exemple en HTML, Python ou JavaScript.
