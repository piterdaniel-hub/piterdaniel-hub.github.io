Mini-glossaire de l'informatique

Les mots essentiels, expliqués simplement. Voir les 65 leçons

Algorithme
Une suite d'instructions précises qui permet de résoudre un problème.
Programmation
L'art d'écrire des instructions qu'un ordinateur peut exécuter.
Serveur
Un ordinateur qui fournit un service (site, fichiers, e-mails) à d'autres machines.
DNS
Le système qui traduit le nom d'un site en adresse numérique, comme un annuaire.
Réseau local (LAN)
Un ensemble d'appareils connectés dans un même lieu : maison, bureau, école.
HTML
Le langage qui décrit la structure d'une page web : titres, textes, images, liens.
CSS
Le langage qui s'occupe de l'apparence : couleurs, tailles, mise en page.
Git et GitHub
Des outils pour sauvegarder, suivre et partager l'évolution d'un projet de code.

Questions fréquentes

Pour qui est ce site ?

Pour toute personne qui veut comprendre l'informatique, apprendre à programmer ou découvrir le développement web, même sans aucune base.

Les contenus sont-ils gratuits ?

Oui, les publications du site sont en libre accès.

Par où commencer ?

Commence par la page Apprendre, puis lis l'article « Maîtrise algorithme, la programmation et le code ». Il pose les bases de tout le reste.

Comment te contacter ?

Le plus rapide est WhatsApp. Tu peux aussi écrire par e-mail ou sur Facebook.

Puis-je installer le site comme une application ?

Oui. Dans Chrome, ouvre le menu ⋮ puis choisis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
